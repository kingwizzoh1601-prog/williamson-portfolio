
# WILLIAMSON — Personal Portfolio

> Building the mind. Mastering the skill. Creating the future.

## Overview

Welcome to my personal portfolio website.

I am a Microprocessor Technology and Instrumentation student at the University of Nairobi, passionate about technology, software development, innovation, entrepreneurship, and continuous learning.

This website introduces who I am, highlights my interests and projects, and provides a way for people to connect with me.

## Features

- **Home:** Introduction, personal branding and featured project.
- **About:** My background, education, interests, leadership experience and vision.
- **Projects:** A showcase of my completed and ongoing projects.
- **Contact:** Contact information and a front-end demonstration form.
- **Responsive design:** Layouts adapted for desktop, tablet and mobile screens.
- **Visual effects:** CSS animations, hover effects and transformations.
- **Navigation:** Consistent navigation across all pages.

## Technologies Used

- HTML5 — Semantic page structure and content.
- CSS3 — Styling, responsive layouts, animations and transitions.
- CSS Grid and Flexbox — Page and component layouts.
- Google Fonts — Custom typography.
- Git and GitHub — Version control and project hosting.
- GitHub Pages — Website deployment.
